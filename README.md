# Machine Learning Capstone Project

## Project Overview
This repository contains a comprehensive machine learning pipeline divided into three tracks: Regression, Classification, and Clustering.

## Datasets
* **Regression:** Motorcycle specifications dataset (`all_bikez_curated.csv`) utilized to predict engine power (hp) based on mechanical features.
* **Classification:** Breast Cancer Wisconsin dataset (`breast_cancer_dataset.csv`) utilized to predict malignant or benign tumor diagnoses based on cell-nucleus measurements.
* **Clustering:** [Dataset Name Pending] utilized for unsupervised pattern recognition.

## Algorithms Implemented
### Regression
* Linear Regression, Ridge, Lasso, ElasticNet, Polynomial Regression
* Decision Tree, Random Forest, Gradient Boosting
* Support Vector Regression (SVR), K-Nearest Neighbors (KNN)

### Classification
* Logistic Regression, Support Vector Classifier (SVC)
* Decision Tree Classifier, Random Forest Classifier
* Gradient Boosting Classifier, K-Nearest Neighbors Classifier

### Clustering
* K-Means Clustering
* Agglomerative Hierarchical Clustering

## Repository Structure
* `data/`: Raw dataset files.
* `notebooks/`: Jupyter Notebooks containing exploratory data analysis, preprocessing, model training, and evaluation pipelines.
* `models/`: Serialized predictive models.
* `app/`: Application deployment files.

## Execution Instructions
1. Clone this repository.
2. Ensure Python 3.x and standard data science libraries (pandas, numpy, scikit-learn, matplotlib, seaborn) are installed.
3. Launch Jupyter Notebook and execute the files in the `notebooks/` directory sequentially.
